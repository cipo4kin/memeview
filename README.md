# 📈 MemeView

> **Интерактивный торговый терминал в стиле TradingView / Binance для торговли абсурдными мем-активами на демо-счете $10,000.**  
> Стек: `FastAPI` (Async) • `PostgreSQL` (asyncpg, SQLAlchemy 2.0) • `Docker Compose` • `Pytest` • `React 18` (Vite, Tailwind, TradingView Lightweight Charts).

---

## ⚡ Быстрый старт (Docker Compose)

Запуск всей экосистемы (БД PostgreSQL + FastAPI бэкенд + React/Nginx фронтенд) в одну команду:

```bash
# 1. Клонировать репозиторий:
git clone https://github.com/cipo4kin/memeview.git
cd memeview

# 2. Поднять контейнеры:
docker compose up --build
```

* 🖥️ **Торговый терминал:** [http://localhost:5173](http://localhost:5173)
* 📖 **Интерактивная Swagger API документация:** [http://localhost:8000/docs](http://localhost:8000/docs)
* 🧪 **Запуск автотестов:**
  ```bash
  cd backend
  pytest -v
  ```

## 🎯 О проекте

**MemeView** — это веб-терминал для торговли мемными индексами и активами с кредитным плечом до x100. Каждому новому пользователю автоматически начисляется демо-баланс **$10,000.00**.

Проект спроектирован с упором на чистый пользовательский интерфейс (Anti-Slop дизайн, темная монохромная тема, быстрый отклик) и строгую финансовую логику на бэкенде.

## 🏗️ Ключевые инженерные решения

### 1. Бэкенд и финансовая логика (FastAPI + SQLAlchemy 2.0 Async)
* **Single Source of Truth:** Фоновый асинхронный воркер в `lifespan` FastAPI эмулирует живые колебания рынка в реальном времени. Цены генерируются и контролируются исключительно сервером.
* **Защита от Race Condition (Lost Update):** При открытии и закрытии позиций используется пессимистическая блокировка строки баланса `SELECT ... FOR UPDATE` (`with_for_update()`). Параллельные или повторные клики не могут загнать баланс в минус.
* **Маржинальная торговля и PnL:** Поддержка плеча (x1, x10, x100). При закрытии позиции реализованный PnL рассчитывается по актуальной рыночной цене с защитой от долговой ямы (`payout = max(0, amount + pnl)`).
* **Слой данных:** Декларативные модели SQLAlchemy 2.0 (`Mapped`, `mapped_column`), асинхронный драйвер `asyncpg`, управление сессиями через Dependency Injection (`get_db`).

### 2. Пользовательский интерфейс (React + Vite + Tailwind CSS)
* **Графика TradingView:** Интерактивный свечной график на базе canvas-библиотеки **Lightweight Charts** с плавной отрисовкой истории и живых тиков.
* **Торговая панель:** Переключатель Long/Short, выбор кредитного плеча, быстрые шорткаты расчета объема маржи (25%, 50%, MAX).
* **Таблица позиций:** Динамический расчет нереализованного PnL для каждого ордера с цветовой индикацией и кнопкой моментального закрытия.

### 3. Автоматизированное тестирование (Pytest)
* Интеграционные тесты на `pytest`, `pytest-asyncio` и `httpx` (`ASGITransport`) с изолированной in-memory базой данных SQLite.
* Покрыты ключевые сценарии: валидация Pydantic, проверка баланса при списании, отказ при нехватке средств (HTTP 400), корректность начисления PnL при закрытии позиции, сброс депозита.
* Время полного прогона тестов — **менее 1 секунды**.

### 4. Контейнеризация и DevOps (Docker)
* **`docker-compose.yml`** поднимает 3 сервиса:
  - `db`: PostgreSQL 16 с volume для персистентности и healthcheck (`pg_isready`);
  - `backend`: образ `python:3.11-slim`, запускающийся после готовности БД;
  - `frontend`: multi-stage сборка Node.js ➔ легковесный Nginx.
* **`.dockerignore`**: настроена изоляция локальных виртуальных окружений и модулей для быстрой и воспроизводимой сборки на любой ОС.

## 📡 Спецификация REST API

* **`GET /api/tickers`** — котировки и суточное изменение (%).
* **`GET /api/chart/{ticker}`** — история 60 минутных свечей (OHLC) для графика.
* **`POST /api/orders`** — открытие ордера (тикер, сторона BUY/SELL, объем, плечо).
* **`POST /api/orders/{id}/close`** — закрытие сделки и выплата на баланс.
* **`GET /api/portfolio`** — текущий баланс и список открытых позиций.
* **`POST /api/reset`** — сброс демо-счета до $10,000 и очистка ордеров.
