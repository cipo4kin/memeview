# 📈 MemeView (Абсурдная мемная биржа на демо-счете)

> **Концепт:** Терминал в стиле TradingView / Binance для торговли абсурдными активами на виртуальном демо-счете.  
> **Стек:** `FastAPI` (Backend) + `PostgreSQL` (asyncpg, SQLAlchemy 2.0) + `Docker` + `Pytest` + `React` (Vite, Tailwind, TradingView Lightweight Charts).

---

## 🎯 Идея и ценность для портфолио

Тимлиды устали от одинаковых резюме с «To-Do листами». **MemeView** решает эту проблему:
1. **Визуальный вау-эффект:** Стильный темный терминал с интерактивными графиками, зелеными и красными свечами, кнопками Long/Short.
2. **Юмор и мемность:** Тимлид начинает торговать акциями Чебупиццы, ржет и залипает на 15 минут в твоем проекте.
3. **Строгая техническая база:** Под капотом - взрослый, надежный REST API с защитой от race conditions, транзакциями, валидацией через Pydantic и чистым React-стейтом.

## 🏗️ Архитектура проекта

### 1. Бэкенд (FastAPI + SQLAlchemy)

* **`GET /api/tickers`** - список всех активов с текущей ценой и изменением за 24ч (%).
* **`GET /api/chart/{ticker}`** - генерация истории минутных свечей для графика TradingView.
* **`POST /api/orders`** - размещение ордера (покупка / продажа):
  - Валидация объема и плеча через Pydantic v2;
  - Проверка баланса демо-счета;
  - Списание средств и запись сделки в БД.
* **`GET /api/portfolio`** - текущий баланс юзера и список открытых позиций.
* **`POST /api/reset`** - сброс баланса обратно до $10,000 и очистка сделок.

---

### 2. Фронтенд (React + Vite + Tailwind CSS)

* **Trading Header:** Текущий баланс демо-счета (`$10,000.00 DEMO`), кнопка сброса счета, кликабельная строка котировок (тикеры и проценты).
* **Центральный график:** Интерактивный свечной график котировок выбранного актива (**TradingView Lightweight Charts**).
* **Панель торговли (Справа):**
  - Выбор плеча: x1, x10, x100 («на всю котлету» 🚀);
  - Ввод суммы сделки с быстрыми кнопками (25%, 50%, MAX);
  - Две большие кнопки: **BUY / LONG (Зеленая)** и **SELL / SHORT (Красная)**.
* **Нижняя панель (Таблица позиций):**
  - Таблица открытых сделок с расчетом нереализованного PnL зеленым/красным цветом.

---

### 3. Автотесты и надежность (Pytest)

* **Тестовый фреймворк:** `pytest`, `pytest-asyncio`, `httpx` (`AsyncClient`), `aiosqlite`.
* **Покрытие ключевых сценариев в `tests/test_api.py`:**
  - Проверка отдачи котировок и типов полей;
  - Генерация свечей и 404 на несуществующий тикер;
  - Размещение сделки и реальное списание средств с баланса ($10,000 ➔ $9,000);
  - Отклонение сделки при нехватке денег (HTTP 400);
  - Сброс баланса до $10,000 и очистка сделок.
* **Запуск тестов:** `python -m pytest -v` (0.6 сек на весь прогон).

## 📦 База данных PostgreSQL, Docker и деплой

* **Основная СУБД - PostgreSQL (asyncpg + SQLAlchemy + Alembic):**
  - Полноценная реляционная БД для коммерческой разработки;
  - Асинхронный драйвер `asyncpg` для максимальной производительности под нагрузкой;
  - Управление схемой и версионирование таблиц через **Alembic** (`alembic upgrade head`);
  - Чистая изоляция слоя данных через Dependency Injection в FastAPI (`get_db`).
* **Контейнеризация (Dockerfile + Docker Compose):**
  - **`Dockerfile`**: легковесная оптимизированная сборка FastAPI бэкенда на базе `python:3.11-slim`;
  - **`docker-compose.yml`**: подъем всей экосистемы в одну команду:
    - `db`: контейнер с PostgreSQL 16 + постоянный том (volume) для сохранности данных;
    - `backend`: контейнер с FastAPI, автоматически применяющий миграции Alembic и запускающий Uvicorn;
    - `frontend`: сборка React, раздаваемая через быстрый Nginx;
  - **Запуск для тимлида одной командой:** `docker compose up --build`.
* **Тестирование и CI:**
  - Запуск автотестов `pytest` перед сборкой или внутри контейнера.

1. **Работа с продакшн-БД и миграциями:** Умение проектировать схемы в PostgreSQL, писать асинхронные запросы через asyncpg/SQLAlchemy и версионировать БД через Alembic.

5. **Связка FastAPI + React:** Опыт построения чистого REST API, обработки CORS, валидации Pydantic и клиентского стейта.
6. **Продуктовое мышление и вкус:** Стильный темный интерфейс торгового терминала, интерактивные графики Recharts и запоминающийся юмор.
